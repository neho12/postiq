# YALI CAKES: מסמך העברה לסשן עיצוב מחדש

## המטרה
לעצב מחדש את האתר מאפס, ברמה גבוהה ויפה יותר, **בלי לשנות את התוכן**.

## כללי ברזל
1. **התוכן קדוש.** כל הטקסטים נמצאים ב־`docs/yali-cakes/CONTENT.md`, מילה במילה. אין לשנות, לקצר, לנסח מחדש או להוסיף טקסט (כולל טקסטים בטפסים, בשאלות הנפוצות ובתקנון). מותר לשנות רק עיצוב, פריסה, טיפוגרפיה, צבעים, תנועה ותמונות.
2. **בלי מחירים.** הבעלים ביקשה במפורש שלא יופיע שום מחיר באתר. אין סימני ₪, אין שורת "מחיר" בסיכום ההזמנה או בהודעת הוואטסאפ. כתוב "בתוספת תשלום" ליד מילויים וטעמים מיוחדים, בלי סכום. "הצעת מחיר" (בקשה להצעה) כן נשאר.
3. **בלי עלי הכותרת הוורודים** (החתיכות הקטנות שצפו בהירו). נמחקו לבקשת הבעלים.
4. **בלי התמונה של יהלי ליד שולחן הקינוחים** (הוסרה מגלריית שולחנות הקינוחים לבקשת הבעלים).
5. **שפה וכיוון:** עברית, RTL, `lang="he"`.
6. **אל תיגע בשאר הריפו.** בריפו `neho12/postiq` יש גם אפליקציה אחרת (`public/`, `api/`, `vercel.json` בשורש). האתר הזה נמצא רק בתיקייה `yali-cakes/`.

## העדפות עיצוב ששמענו מהבעלים (בעקבות ניסיונות קודמים)
- רוצה **רמה גבוהה ומינימליסטית**. הורידה במפורש אפקטים "מוגזמים": כיפה שמתרחבת בהירו, עוגה שנבנית בגלילה, סוכריות בפרלקסה, קו זילוף לאורך הדף, פסי טקסט נעים, סמן עכבר מעוצב, גרעיניות, גלריה שנתקעת וזזה הצידה.
- **נשאר ואהוב:** מסך פתיחה שבו הלוגו המלא (YALI cakes) **מצטייר בקו ואז מתמלא**, ואז שתי שכבות צבע (חום ורוד) עולות וחושפות את האתר. גלילה חלקה (Lenis) ודעיכה עדינה פנימה של בלוקים בפעם הראשונה. הוא תמיד **נפתח בראש הדף** (גם אחרי רענון), אלא אם יש `#hash` בכתובת.
- הסרטון בהירו **סטטי** (בלי זום או תזוזה בגלילה).
- שדות הטפסים: **עמודה אחת, כולם באותו רוחב (עד 520px) ובאותו גובה (48px)**, גם שדות תאריך ושעה (חשוב באייפון).
- תמונות העוגות בגלריות: צריכות להיות **שלמות ובלי חלק חתוך**. חלק מהתמונות נחתכו מחדש כך שהעוגה יושבת על רקע לבן נקי עם צל רך. אם משלבים תמונות חדשות, לחתוך באותה צורה.

## מצב טכני נוכחי
- **עודכן:** האתר נבנה מחדש כ־HTML/CSS/JS סטטי רגיל: `yali-cakes/index.html` (כל הטקסט, כולל ה־SEO), `styles.css` (עיצוב ותנועה), `app.js` (טפסים, סיכום חי, הודעות וואטסאפ, גלריות, מסך הפתיחה, Lenis, דעיכה עדינה). `vendor/` מכיל רק את `lenis.min.js`. אין יותר React, `support.js`, `enhance.css` או `enhance.js`.
- מספר הוואטסאפ מוגדר בראש `app.js` (`WHATSAPP`).
- **בבנייה מחדש מומלץ HTML/CSS/JS סטטי רגיל** (בלי React ובלי runtime של x-dc), כל עוד **ההתנהגות נשמרת**:
  - לחיצה על כרטיס סוג עוגה פותחת את הטופס שלו (כל סוג עם שדות, קבוצות בחירה ותמונות דוגמה משלו, ראו `CONTENT.md`).
  - שליחה = פתיחת וואטסאפ: `https://wa.me/972532850540?text=<הודעה מקודדת>`. מבנה ההודעה (שורות `שם שדה: ערך`, "לא צוין" לשדה ריק) מופיע כדוגמה בכל טופס ב־`CONTENT.md`. ההודעה כוללת רק שדות שבטופס, **בלי מחיר**.
  - טפסי "הצעת מחיר" לסדנאות ולשולחנות קינוחים נפתחים בלחיצה על הכפתור ושולחים הודעת וואטסאפ דומה.
  - "סיכום ההזמנה" מתעדכן חי בצד הטופס.
  - גלריות עם חצים וגלילה אופקית (scroll-snap), גלריית "קצת מהעבודות שלנו" ו"עוד" בכל אזור.
  - שאלות נפוצות כאקורדיון (`<details>`), ותנאים/פרטיות/נגישות כ־`<details>` בפוטר (נפתחים גם דרך `#terms`, `#privacy` ו־`#accessibility`).
  - Google Analytics: `G-BJN2SX08TM`. שומרים את התג.
  - נגישות: קישור "דלג לתוכן", `aria`, מיקוד גלוי, `prefers-reduced-motion`.
- הפריסה: אתר סטטי, בלי build. ב־Vercel: Root Directory `yali-cakes`, Framework Preset: Other, Output Directory **ריק**. אפשר גם להעלות את התיקייה ל־Netlify.
- באייפון: ההודעה "Open Link" כשלוחצים על וואטסאפ היא הודעת מערכת של הדפדפן/האפליקציה ולא ניתן להסיר אותה מהקוד.

## איך לוודא שהתוכן לא השתנה
אחרי הבנייה: לפתוח את האתר בדפדפן אוטומטי (Playwright), לעבור על כל הסקציות ועל כל טופס, ולהשוות את הטקסט המוצג ל־`CONTENT.md` (גם כותרות, תוויות שדות, אפשרויות בחירה, שאלות נפוצות ותקנון). להציג בדוח כל הבדל.

הבדיקה הזו אוטומטית: `node docs/yali-cakes/check-content.js` (דורש את החבילה `playwright`). היא בודקת גם placeholders, הודעות הוואטסאפ, קבצי התמונות והטקסט החלופי בכל גלריה, ושאין ₪ בדף.

## מה שלא ניתן לעשות
אין כלי ליצירת תמונות או וידאו פוטוריאליסטיים. עיצוב מחדש צריך להסתמך על התמונות הקיימות, איורי SVG וקוד. אם צריך צילומים חדשים, לבקש מהבעלים.
